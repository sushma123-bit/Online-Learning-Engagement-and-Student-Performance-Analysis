# Online Education Analytics Project

## Overview
Analysis of student engagement, performance, and dropout patterns in an online education dataset (~32,500 student records), using SQL for analysis and Power BI for visualization.

## Files
- **online_education_dataset.csv** – Raw student data (demographics, clicks, scores, engagement/performance/risk levels, pass/dropout flags)
- **queries.sql** – SQL analysis queries (totals, engagement/performance/risk breakdowns, dropout rates, regional & education-level insights)
- **sushma.pbix** – Power BI dashboard built on the dataset

## Key Metrics Covered
- Total students, average score, average clicks
- Pass vs. dropout rates
- Engagement, performance & risk level breakdowns
- Clicks vs. score correlation
- Dropout rate by engagement/performance level
- Regional & educational background analysis

## Tools Used
- SQL (MySQL/PostgreSQL syntax)
- Power BI
